# About

Welcome to **SentinelMaster**.

This repository documents my journey as a security professional. My goal is to share practical techniques, tools, and lessons learned while building and operating modern security operations.

Rather than focusing on theory alone, this repository emphasizes **real-world implementations** developed through:

- Threat Hunting
- Detection Engineering
- Digital Forensics & Incident Response (DFIR)
- Microsoft Security
- Cloud Security
- Security Automation
- AI-Assisted Security Operations

Most of the current content is built around **Microsoft Sentinel** and **Microsoft Defender XDR** because those are the primary technologies I use professionally today. As I continue learning and growing, this repository will expand to include Python development, cloud security, automation, AI, and additional security platforms.

My goal is to create practical resources that other analysts, engineers, and defenders can learn from, adapt to their own environments, and build upon.

# Engineering Philosophy

Every project in this repository follows the same engineering lifecycle.

```text
Threat Intelligence
        ↓
Threat Hunting
        ↓
Understand Normal
        ↓
Establish Baselines
        ↓
Operationalize with Workbooks
        ↓
Build Detections
        ↓
Automate Response
        ↓
Continuously Improve
```

The objective isn't simply to collect KQL queries or scripts.

The goal is to demonstrate how modern security engineering evolves from understanding normal behavior to building scalable detection, investigation, and response capabilities.
