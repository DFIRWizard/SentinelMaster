# Enterprise Network Baseline Workbook

> A Microsoft Sentinel workbook for operationalizing baseline threat hunting using Microsoft Defender XDR network telemetry.

---

# Overview

The Enterprise Network Baseline Workbook helps security teams establish normal network behavior and quickly identify meaningful deviations.

Instead of searching only for known indicators of compromise (IOCs), this workbook supports **baseline-driven threat hunting** by comparing current activity against historical behavior.

This workbook was developed using the **PEAK Threat Hunting Framework** and is intended to support daily SOC operations, proactive threat hunting, and detection engineering.

---

# Key Questions Answered

The workbook helps analysts answer questions such as:

- Has overall network activity changed?
- Are new external destinations appearing?
- Are uncommon processes communicating externally?
- Are Living-off-the-Land Binaries (LOLBins) generating network traffic?
- Have scripting engines increased network activity?
- Have new remote administration tools appeared?
- Are uncommon ports being used?
- What raw events explain the deviation?

---

# Features

## Executive Overview

Provides a high-level operational summary including:

- Daily Network Activity
- Network Activity vs Prior 30-Day Baseline
- Network Scope Distribution
- Baseline Health Status

---

## Destination Deviations

Identifies:

- New external domains
- Rare external domains
- Previously unseen destinations

---

## Process Deviations

Highlights:

- Rare network processes
- Significant increases in network activity
- Processes communicating from only a few devices

---

## LOLBin Activity

Monitors common Windows binaries frequently abused by attackers, including:

- PowerShell
- CMD
- Rundll32
- Mshta
- Regsvr32
- Certutil
- Bitsadmin
- WMIC

---

## Scripting Engines

Tracks network activity generated by scripting environments such as:

- PowerShell
- Python
- Node.js
- Java
- Bash (WSL)
- .NET

---

## Remote Administration

Compares observed remote administration tools against an approved tool list.

Examples include:

- ScreenConnect
- TeamViewer
- AnyDesk
- RustDesk
- BeyondTrust
- MeshCentral
- Splashtop

---

## Ports & Protocols

Highlights:

- New ports
- Sensitive external ports
- Previously unseen protocols

---

## Network Event Explorer

Provides raw DeviceNetworkEvents for investigation after a deviation is identified.

# Data Requirements

This workbook requires Microsoft Defender XDR Advanced Hunting data.

# Methodology

This workbook follows a baseline-driven hunting methodology.

```
Threat Intelligence
        ↓
Baseline Threat Hunt
        ↓
Historical Baseline
        ↓
Operational Workbook
        ↓
Deviation Review
        ↓
Investigation
        ↓
Detection Engineering
        ↓
Automation
```

The goal is to continuously improve visibility by converting recurring observations into detections and automated response.

# Installation

1. Download the workbook JSON.
2. Open Microsoft Sentinel.
3. Create a new Workbook.
4. Select **Edit**.
5. Open **Advanced Editor**.
6. Paste the JSON.
7. Save the workbook.

---

# Customization

Before using the workbook in production, review and customize:

- Approved remote administration tools
- Infrastructure exclusions
- Baseline duration
- Rare process thresholds
- Spike thresholds
- Device filters

Every environment is different, and thresholds should be tuned based on organizational behavior.
